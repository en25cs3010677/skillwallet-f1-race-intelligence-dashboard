# Project demonstration script

**Target length:** 3–5 minutes. Record only after the final workbook review and, if required, Tableau Public publication.

1. **Project goal (20–30 sec):** Introduce the Formula 1 Race Intelligence Dashboard and its decision-support goal. State that the supplied dataset is simulated.
2. **Data and preparation (30–45 sec):** Show the source workbook and prepared CSV. Explain the known caveats listed in `DATA_NOTES.md`.
3. **Dashboard (90–120 sec):** Walk through driver championship points, team points, wet/dry race counts by season, average race time by circuit, and DNFs by team. Demonstrate available interactions.
4. **Story (45–60 sec):** Step through the story points and summarize the dataset-specific observations without presenting them as real F1 history.
5. **Quality and delivery (30–45 sec):** Report the measured checks from `PERFORMANCE_AND_VALIDATION.md`. Show the Tableau Public embed only if publishing and web integration are complete.
6. **Close (10 sec):** Point to the repository README, phase sequence, data, workbook, and documentation.
