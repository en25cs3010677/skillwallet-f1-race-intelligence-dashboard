# Web integration

## Current status

The packaged workbook is local and has not been published to Tableau Public. No live dashboard URL or embedded page is available yet. Complete the steps below after the owner reviews and publishes the workbook.

## Publish and embed

1. Open `F1_Race_Intelligence_Dashboard.twbx` in Tableau Public.
2. Review the workbook and confirm that the data caveat is clear.
3. Publish it to the intended Tableau Public profile.
4. Copy the published workbook URL and replace the placeholder below.
5. Add the final iframe or Tableau embed code to the SkillWallet project page only after confirming the target page and access requirements.
6. Verify the embed in a browser at desktop and mobile widths.
